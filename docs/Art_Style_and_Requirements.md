# 《Panic Basket》美术风格与美术需求文档

## 1. 风格定位

本项目采用俯视角 2D 像素风。整体气质是“便利店荧光灯下的喜剧混乱”：画面要紧张，但不能沉重；警报红、商品黄、冷柜蓝和出口绿要清楚区分功能。

参考来源为 `Wiki/top_down_2d_games.html`：

- `Hotline Miami`：高速顶视动作、强烈危险色。
- `Monaco`：潜入信息可读性和俯视建筑语义。
- `Moonlighter`：商品、货架和战利品的语义清晰度。
- `Nuclear Throne`：粗颗粒像素和夸张动势。
- `Streets of Rogue`：小人比例和系统混乱感。

## 2. 视觉原则

- 所有玩法关键信息优先可读：玩家、警卫、视野锥、出口、高价值物品必须一眼识别。
- 像素颗粒要明确，避免柔化、复杂渐变和写实光影。
- 单个角色以 16x16 或 24x24 像素语义设计，放大显示。
- 商品图标以颜色和轮廓区分：汽水圆柱、面包长条、洗衣液瓶、电子产品盒、金色稀有物。
- 场景瓦片以功能分区上色：货架蓝、地面灰、出口绿、危险红、稀有黄。

## 3. 色彩规范

- 地面基底：深灰蓝 `#202832`、`#2b333d`
- 货架：蓝灰 `#3f5f7a`、高光 `#6f91ad`
- 玩家：青绿 `#65e0a3`
- 警卫：警报红 `#f45b69`
- 普通商品：黄 `#ffd166`、橙 `#f79d65`、青 `#6ec6ff`
- 稀有目标：金色 `#ffe66d` 搭配白色闪光
- 出口：绿色 `#76e39a`
- 视野锥：半透明红

## 5. 试制资产案例

`assets/pixel_asset_sheet.svg` 提供一张可检查的像素资产样张，包含：

- 玩家小偷。
- 警卫。
- 收银员。
- 普通商品。
- 高价值金色目标。
- 地面、货架、出口和危险提示瓦片。

原型内的实际渲染使用 `src/game.js` 中的 canvas 像素绘制函数，确保所有关键对象即使不加载外部图片也能稳定显示。

## 6. 后续生产清单

- 玩家 4 向移动动画，每方向 3 帧。
- 警卫巡逻、追逐、眩晕 3 组动画。
- 商品 8-12 种，包括低价值、中价值和高价值。
- 货架、冷柜、收银台、促销篮、湿滑地面瓦片。
- 投掷命中特效、拾取闪光、警报闪屏和撤离结算 UI。
