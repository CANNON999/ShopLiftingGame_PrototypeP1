# 《Panic Basket》游戏设计文档

## 1. 概念摘要

`Panic Basket` 是一个俯视角 2D 像素风动作原型。玩家在 60 秒内闯入一间混乱便利店，快速抢夺商品，寻找随机刷新的高价值目标，并把货架上的普通商品当作临时武器投掷警卫。玩家可以选择保守撤离，也可以在警卫追逐和警报升级中继续冒险，追求更高分。

核心体验对应关系：

- 有限时间：全局倒计时制造持续压力。
- 混乱、惊险、幽默：拥挤货架、滑倒区、警卫视野、随机高价值物品和夸张商品投掷共同制造喜剧化危险。
- 快速抉择并抢夺商品：玩家需要在价值、距离、风险和背包容量之间即时取舍。
- 偶然发现高价值目标：每局随机生成一个闪光高价值商品，靠近后才更容易识别。
- 随手商品正面对抗敌人：已抢商品既是分数来源，也是投掷弹药。
- 高风险高收益：继续深入会获得高价值物品，但警卫压力和损失风险同步上升。

## 2. 核心循环

1. 观察货架、警卫路线和出口。
2. 冲进店内拾取商品，积累战利品价值。
3. 发现高价值闪光目标后决定是否冒险深入。
4. 警卫追来时，用背包里的商品投掷击晕，或用冲刺脱离。
5. 在倒计时结束前跑到出口结算。
6. 根据带出的总价值、剩余时间、连续拾取和是否偷到高价值目标获得评分。

## 3. 主要机制

### 移动与冲刺

- WASD 或方向键移动。
- 空格冲刺，短时间提速，有冷却。
- 冲刺用于穿越警卫视野、抢最后一个高价值物品或冲向出口。

设计依据：动作游戏中的短冷却位移可以给玩家制造“我能再赌一下”的主动性。冲刺不是单纯逃命按钮，而是把风险窗口转化成操作机会。

### 拾取与背包容量

- 靠近商品按 E 拾取。
- 每个商品有价值和重量。
- 背包容量有限，玩家不能无脑全拿。
- 普通商品数量多、价值低、适合当弹药；高价值商品稀少、分数高、重量也更高。

设计依据：背包容量把“抢更多”变成选择题。玩家必须在分数收益、武器储备和移动安全之间进行实时权衡。

### 随机高价值目标

- 每局从电子产品、金色玩具、收银台珍品等位置中随机生成一个高价值目标。
- 高价值目标带有闪光提示，但通常靠近警卫巡逻区。

设计依据：不确定性让路线规划从固定背板变成临场判断。随机奖励能制造惊喜，也能强化“再冲一次”的高风险动机。

### 商品投掷战斗

- 按 F 或鼠标点击向指针方向投掷背包里的最后一件商品。
- 命中警卫会短暂击晕。
- 投掷商品会失去对应分数潜力。

设计依据：把战利品兼作弹药，可以自然形成“收益即资源”的张力。玩家不是获得独立武器，而是把已经抢到的东西消耗掉来换取生存空间。

### 警卫视野与追逐

- 警卫巡逻时有锥形视野。
- 玩家进入视野会提升警戒并触发追逐。
- 被警卫抓到会丢失部分商品并损失时间。
- 击晕警卫会短暂降低压力，但不能永久解决威胁。

设计依据：可读的视野锥让风险具象化。惩罚采用“丢货和扣时间”而不是立即失败，能保持节奏爽快，同时让错误仍然疼。

### 撤离与结算

- 出口位于地图底部。
- 玩家可以随时撤离。
- 倒计时结束仍未撤离则失败并只获得少量安慰分。

设计依据：随时撤离让玩家承担自己的贪心后果。成功撤离强化“带着战利品逃出来”的爽感。

## 4. 关卡与节奏

原型关卡是一间紧凑便利店：

- 外围：入口和出口，安全但商品少。
- 中区：零食、饮料、日用品货架，收益稳定，风险中等。
- 深区：电子柜、收银台、稀有商品，收益高，警卫巡逻密集。
- 混乱点：地面湿滑区、散落促销篮和拥挤货架改变走位。

节奏目标：

- 0-15 秒：玩家快速拿到低价值商品，熟悉局面。
- 15-40 秒：发现高价值目标，警卫开始追逐。
- 40-60 秒：背包接近满载，撤离与贪心形成最终决策。

## 5. 美术与音画方向

- 像素风 2D，16-bit 街机质感。
- 俯视角清晰读图，强调货架、视野锥、闪光商品和出口。
- 色彩以便利店荧光绿、警报红、货架蓝、商品黄形成多色对比。
- 角色比例夸张，动作读起来要滑稽而敏捷。

参考方向来自 `Wiki/top_down_2d_games.html` 中的纯 2D 俯视角案例：借鉴 `Hotline Miami` 的高压顶视动作、`Monaco` 的潜入可读性、`Moonlighter` 的商店物品语义、`Nuclear Throne` 的粗颗粒动势，以及 `Streets of Rogue` 的系统混乱感。

## 6. 原型范围

当前 JavaScript 原型需要实现：

- 可移动、可冲刺、可拾取、可投掷的玩家。
- 多种商品，包含普通商品和随机高价值商品。
- 至少两个警卫，具备巡逻、视野、追逐、被击晕状态。
- 倒计时、背包容量、分数、撤离和失败结算。
- 像素风 canvas 渲染与基本 HUD。

暂不实现：

- 多关卡流程。
- 复杂 NPC 生态。
- 存档、商店升级、联机。
- 真正的音频制作。

## 7. 成功标准

- 玩家打开 `index.html` 即可开始游玩。
- 一局可以在 60 秒内完成，并能成功或失败结算。
- 玩家能明显感受到“多拿一点还是先跑”的风险收益抉择。
- 商品投掷会消耗潜在分数并改变警卫压力。
- 画面资产和文档均保持像素风方向一致。
